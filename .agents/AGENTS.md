# กฎและข้อมูลเฉพาะสำหรับการพัฒนาระบบขอบาร์โค้ด (Request Barcode Application Rules)

- **ข้อมูลผู้รับอีเมล:** อีเมลปลายทางสำหรับส่งคำขอบาร์โค้ดคือ `wh.frame@visionventures.co.th`
- **หัวข้ออีเมล (Subject):** หัวข้ออีเมลขอบาร์โค้ดคือ "รบกวนขอบาร์โค้ดสำหรับติดตั้งหน้าสาขาเพิ่มเติม"
- **การอธิบายช่องค้นหา (Search Label):** ระบุข้อความค้นหาเป็น "ค้นหาสินค้าจาก ชื่อรุ่น หรือ บาร์โค้ดเก่า"
- **หน่วยนับสินค้า (Quantity Unit):** ในการแสดงผลจำนวนของรายการสินค้าในอีเมล ให้ใช้หน่วยเป็น "ชิ้น" (แทนคำว่า "ดวง")
